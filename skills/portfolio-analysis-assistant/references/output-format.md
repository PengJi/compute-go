## 五、 组合全局风险排查
- **大类资产穿透**：防守类 X% / 核心宽基 X% / 进攻类 X% / 其他 X%。
- **同质化预警**：识别出哪些表面不同、底层同源的主题。
- **压力测试推演**：
  - 如果权益资产整体回调 15%：组合预估回撤 X%。
  - 如果特定主题回调 20%：组合预估回撤 X%。
- 可选增强：压力测试金额口径——用户提供了组合总金额时，逐情景同时给出预估亏损金额，与百分比口径并列。
