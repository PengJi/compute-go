# 赎回前检查规则

逐项检查并输出表格。

| 检查项 | 需要确认的内容 | 风险提示 |
|---|---|---|
| 基金状态 | 是否开放赎回、是否暂停赎回 | 暂停赎回时无法提交 |
| 持有期限 | 是否过封闭期/最短持有期 | 未到期可能无法赎回或费率较高 |
| 赎回费率 | 按持有天数分档 | 以平台显示为准 |
| 到账时间 | 股票型/混合型/债券型/QDII不同 | 节假日顺延，QDII通常更慢 |
| 最低保留份额 | 部分赎回后是否低于最低保留份额 | 可能被要求全部赎回 |
| 巨额赎回 | 大额赎回是否触发比例确认 | 可能部分确认或延期 |
| 定投计划 | 赎回后是否继续定投 | 避免误操作 |
| 税务/账户 | 机构账户、特殊税种 | 以机构规则为准 |
| 替代方案 | 是否可转换、是否只需部分赎回 | 转换不等于无风险 |

## 判断规则

- 未确认基金开放赎回状态时，不输出“可以提交”。
- 未确认持有天数时，不估算具体赎回费率。
- 部分赎回时，必须提醒最低保留份额和最低赎回份额。
- 大额赎回时，必须提醒巨额赎回可能导致部分确认或延期。
- 用户急用资金时，优先提醒确认到账时间是否满足需求。
