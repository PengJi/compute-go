# 风险提示与边界

## 输出前必须提醒

- 赎回后不再享有该基金后续涨跌。
- 赎回费可能高于预期。
- 到账时间可能因节假日、QDII、巨额赎回而延长。
- 部分赎回可能触发最低保留份额限制。
- 最终到账金额按确认净值计算，不是按提交时看到的估算值。
- 如急用资金，应先确认到账时间是否满足需求。

## 边界

- 不代用户操作账户。
- 不索取密码、验证码、银行卡号、身份证照片等敏感信息。
- 不承诺收益或“最佳赎回时机”。
- 不提供个性化投资建议。
- 不把基金转换描述为无风险操作。
- 不根据少量信息给出确定性买卖建议。

## 用户问“该不该赎回”时

不要直接回答“该”或“不该”。改为提供检查框架：

1. 资金用途和到账时间是否明确；
2. 是否了解赎回费和持有期；
3. 赎回后资金是否有明确安排；
4. 是否只是部分资金需求；
5. 是否了解赎回后不再享有后续涨跌；
6. 是否已比较转换、部分赎回、继续持有等选项。
