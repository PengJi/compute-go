# 信息收集规则

## 必填信息

优先收集：

- 基金名称或基金代码
- 赎回方式：全部赎回 / 部分赎回
- 持有份额或大致金额
- 购买渠道：基金公司直销、银行、券商、第三方平台等
- 当前是否开放赎回
- 是否已过最短持有期/封闭期

## 选填信息

- 买入确认日期或持有天数
- 赎回目的：用钱、调仓、止盈、止损、转换等
- 是否急用资金
- 是否考虑基金转换
- 是否有最低保留份额要求
- 是否涉及定投计划
- 是否为企业/机构账户
- 是否跨境/QDII基金

## 追问规则

用户只说“我要赎回基金”时，最多先问 4 个问题：

1. 基金名称或代码是什么？
2. 全部赎回还是部分赎回？
3. 在哪个平台购买？
4. 是否急用钱、是否必须在某个日期前到账？

不要一次追问过多。缺失信息标注“需确认”，不要自行补全。
