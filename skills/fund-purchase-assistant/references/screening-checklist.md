# 基金筛选检查清单

与 SKILL.md 工作流程配合使用。本清单的重点是“去哪查、怎么判断”，查不到就按“数据真实性”规则标注“未能核实”，不填估计值。

## 一、用户匹配（对应第 1、2 步）

- [ ] 投资目标、期限、回撤承受力已确认，或已声明按保守假设继续
- [ ] 用“期限 × 回撤承受力”映射表定位画像档位
- [ ] 资金确认为闲钱，非 1—3 年内确定要用的钱
- [ ] 现有持仓与集中度已了解

## 二、基金类型匹配（对应第 3 步）

- [ ] 类型与画像档位匹配（货币/债券/混合/股票/指数/主动）
- [ ] 行业主题基金已重点提示高集中度与追高风险
- [ ] QDII 已提示汇率、境外市场风险与较长申赎周期
- [ ] FOF 已提示双重收费与低弹性

## 三、主动基金核心指标（对应第 4 步）

- [ ] 业绩：天天基金或晨星查 3 年、5 年年化回报，看同类四分位排名，优先长期稳定居前 1/2
- [ ] 是否持续跑赢业绩比较基准：以基金定期报告披露为准
- [ ] 最大回撤：天天基金或晨星查历史最大回撤，与用户回撤承受力档位对比
- [ ] 夏普/索提诺比率：晨星或基金年报查询，与同类横向比较，不看绝对值
- [ ] 经理任职年限：以基金公告或年报确认现任起点，警惕挂名基金经理
- [ ] 经理是否经历完整牛熊：从业年限是否跨过至少一轮大级别涨跌
- [ ] 投资风格稳定、知行合一：对比历次季报持仓与宣称的风格
- [ ] 规模：警惕低于约 5000 万元的清盘风险，以及数百亿主动权益基金灵活性下降
- [ ] 费率：合并管理费+托管费+申购/销售服务费，与同类中位数比较
- [ ] 基金公司投研体系：公开资料了解团队规模与稳定性

## 四、指数基金核心指标（对应第 4 步）

- [ ] 跟踪指数清晰、可理解，成分与行业集中度已提示
- [ ] 跟踪误差：以基金定期报告披露口径为准，与同类对比
- [ ] 费率较低：管理费与托管费合并看
- [ ] 规模与流动性：规模过小同样有清盘风险
- [ ] 指数估值仅作风险提示，不做择时承诺

## 五、买入策略（对应第 5 步）

- [ ] 一次性 vs 定投已按波动特征与投资期限说明
- [ ] A/C 份额：短持有期或不确定选 C，长期选 A，平衡点按具体费率结构估算
- [ ] 单只基金占比有上限
- [ ] 资产类别已分散，且用季报前十大重仓股对比排除“假分散”
- [ ] 复盘周期与再平衡规则已设定
- [ ] 持有逻辑与退出条件已写明

## 六、风险提示

- [ ] 已提示历史业绩不代表未来
- [ ] 未核实数据已标注“未能核实”
- [ ] 输出末尾包含合规声明
