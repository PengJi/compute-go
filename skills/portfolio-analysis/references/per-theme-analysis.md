# 单主题分析框架（通用）

对自动归纳出的每一个主题，输出以下指标与诊断：

## 1. 基础数据
- **当前权重**：该主题总市值 / 组合总资产。
- **区间绝对收益率**：该主题内部所有持仓的加权收益率。
- **收益贡献度（绝对贡献）**：当前权重 × 区间收益率，单位 %（如 +6.0%）。各主题绝对贡献加总即组合总收益的估算，口径与 `portfolio-overview.md`、`output-format.md` 保持一致。
    - 如需展示"该主题贡献占组合总收益的比例"，仅在组合总收益显著非零（如绝对值 >1%）时计算；组合总收益接近零时直接省略——除以接近零的数会产生量级失真的误导结论。

## 2. 表现诊断
- **判断逻辑**：该主题收益是正还是负？跑赢还是跑输基准？该主题的涨跌是受基本面驱动、政策刺激还是情绪炒作？
- **示例表述**：“`科技与半导体`主题贡献了最大的正收益，说明前期超配抓住了该主线行情；`医药生物`产生负贡献，主要受制于……”

## 3. 主题内部集中度预警
- 如果该主题内**仅持有一只股票/基金**：提示“单一标的风险，缺乏内部对冲”。
- 如果该主题内持仓极其分散（如持有超 10 只同类基金/股票）：提示“过度分散，丧失弹性”。
