# 全局汇总与穿透分析

在逐一分析聚类主题后，必须汇总至全局层面，执行以下三项检查：

## 1. 整体绩效快照
- 对比基准（如沪深300、中证全债，或构建复合基准）。
- 计算组合总收益率、年化波动率、最大回撤、夏普比率。
- **数据可得性**：年化波动率、最大回撤、夏普比率需要区间净值时间序列。只有期初期末数据时跳过这三项，并在报告注明"数据不足，未计算"——用区间收益推算这三项属于编造数据，宁可留空。

**数据可得时的增强分析**（前提永远是真实数据已核实，与上面"禁止编造"的边界不冲突）：
- 联网能核实真实数据（来源与日期留痕）时，鼓励做深一层：逐腿基准对比（各主题 vs 对应指数）、年化收益（区间超过 1 年时）、历史情景对照（如以某次真实大跌周为样本推演组合表现）。
- 用户提供组合总金额时，压力测试同时给出百分比与金额口径，让亏损体感更直观。
- 边界不变：情景推演（压力测试）允许用假设；但年化波动率、最大回撤、夏普比率这类点估计风险指标仍需真实净值时间序列，用"假设倍数合成影子组合"推算这三项仍然禁止，数据不足时如实标注"数据不足，未计算"。
- 风险排查可纳入费率与交易结构风险（如 QDII 场内溢价、汇率敞口），同样要求数据可核实。

## 2. 同质化与拥挤度排查
- 检查自动归纳出的主题之间，底层资产是否同源。例如：如果归纳出“人工智能”、“半导体”、“信创”、“消费电子”四个主题，需指出它们底层高度相关，实质是单一押注科技赛道。
- 计算“高风险/进攻型主题”的总权重，评估组合的真实风险敞口。

## 3. 极端情景压力测试
推演极端情景对组合的冲击，并计算受损金额：
- **情景 A：宽基/系统性风险**（如果权益类整体下跌 15%） -> 组合回撤预估。
- **情景 B：特定风格/行业暴跌**（如果组合中权重最大的 2-3 个同质化主题暴跌 20%） -> 组合回撤预估。
- **情景 C：利率或汇率冲击**（如长端利率大幅上行，或人民币大幅升值） -> 组合抗跌能力。
